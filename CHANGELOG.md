# Changelog

All notable changes to DevFlow AI will be documented here.

## [1.0.0] — 2026-11-11

### ✨ New Features
- Initial release of DevFlow AI
- AI-powered code review via CLI (`devflow review`)
- Automatic changelog generation (`devflow changelog`)
- Code quality analysis (`devflow analyze`)
- GitHub Action integration for PR review automation
- Detects critical issues: hardcoded passwords, secrets, eval() usage
- Detects warnings: bare except, debug prints, blocking sleep
- Generates structured Markdown review reports with severity scores
